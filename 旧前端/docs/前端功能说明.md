# 前端功能说明

日志汇聚与审计分析平台的前端（`D:\log-Frontend`）。三个页面 + 一套平台外壳，
Vue 3 + TypeScript + Vite + Pinia，表格与筛选控件用 Element Plus，图表用 ECharts。

- 代码与接口路径的字段级约定见 `docs/` 下三份《后端接口契约》
- 本文只讲**功能**：每个页面能做什么、有什么行为、依赖后端哪些接口
- 界面样式还原自静态原型 `work/heartbeat-dashboard/{index,logs,integrity}.html`

## 2. 客户端心跳监控 `/clients/heartbeat`

### 概览与图表

- **5 张概览卡**：客户端总数（含 Linux/Windows 拆分）、在线客户端（在线率）、
  延迟客户端、离线客户端、近 5 分钟日志量（N 台日志正常）
- **在线趋势图**：在线客户端曲线 + 客户端总数虚线，可切换近 6 / 12 / 24 小时
- **运行状态分布**：环形图（在线/延迟/离线占比）+ 状态数量清单 + 最近刷新时间

### 客户端列表（14 列）

序号、IP 地址、服务器名称、系统类型、系统版本、Fluent Bit 版本、心跳周期、
最近心跳（`N 秒前`）、心跳延迟（`N 秒`）、最后日志时间、近 5 分钟日志量、
**心跳状态**（在线/延迟/离线）、**日志状态**（正常/无日志/积压/中断）、操作。

### 功能

| 功能 | 说明 |
|---|---|
| 搜索 | 服务器名称 / IP 地址，回车即查 |
| 筛选 | 心跳状态、系统类型，可与搜索组合 |
| 分页 | 每页 20 条起可选，页码窗口（几十页时自动省略中间页） |
| 查询 / 重置 | 显式点按钮才请求，不在每次输入时打接口 |
| **详情弹窗** | 客户端 ID、IP、系统、版本、Fluent Bit、心跳周期、心跳状态、心跳延迟、日志状态、最后日志、近 5 分钟日志量、缓冲区积压、输出通道、**CPU 使用率、内存占用**、最近心跳、记录创建/更新时间 |
| **日志弹窗** | 该客户端最近 20 条日志，终端风格展示，可手动刷新 |
| 导出 CSV | 导出**当前查询结果**（带 UTF-8 BOM，Excel 打开中文不乱码） |
| 刷新 | 手动刷新 + 每 5 秒自动刷新 |

### 自动刷新策略

- 概览 + 列表每 **5 秒**，趋势数据每 **60 秒**
- 用递归 `setTimeout` + 执行锁：接口慢于 5 秒时**不会叠加并发请求**
- 标签页隐藏时暂停请求，切回来立即刷新一次
- 首屏立即加载，不等第一个 5 秒周期

## 3. 融合日志管理 `/logs`

### 概览与类别

- **4 张统计卡**：今日融合日志（较昨日同期增减）、近 5 分钟接收（条/秒吞吐）、
  接入主机（N 台有日志 + 管道状态）、实时接收状态（接收中 / 已暂停 / 连接已断开 + 最后接收时间）
- **类别标签页**：实时总览 + 七大类，带条数角标

### 两套筛选

| 总览页 | 分类页 |
|---|---|
| 主机名称 / IP 地址 | 检索字段（下拉，**只列后端标记可检索的字段**） |
| 系统类型 | 字段值（按类型自动切换控件：数字输入框 / 日期选择器 / 文本） |
| 时间范围（起止日期时间） | 字符串按"包含"匹配，数字与时间按"相等"匹配 |
| 查询 / 重置 | 按字段查询 / 重置 |

### 动态列表格

- 列**完全由后端类别元数据驱动**，七类共用同一个表格组件
- 表头格式 `英文名（中文名）`，例如 `event_time（事件时间）`
- 总览固定展示 8 个字段：事件时间、主机、系统、日志类别、类型、融合摘要、结果、来源 IP
- 单元格按类型/字段渲染：时间转本地时区、类别显示中文标签、结果带颜色徽标、类型码等宽字体
- 分页每页 20 / 50 / 100 条（后端上限 100）

### 实时（SSE）

| 行为 | 说明 |
|---|---|
| 新日志推送 | 通过 SSE 逐条接收，插入总览列表顶部并**短暂高亮** |
| 暂停 / 继续实时 | 只是页面不再插入，**不影响后端采集** |
| 有筛选条件时 | 新日志不直接插入（否则会出现不符合条件的行），改为显示"收到 N 条新日志，点击刷新" |
| 第 2 页及以后 | 同样进入待刷新计数，不打断当前浏览位置 |
| 断线 | 浏览器自动重连；重连成功后**重新查询第一页**补齐断线期间数据 |
| 连接状态 | 顶部统计卡实时显示"接收中 / 已暂停 / 连接已断开" |

### 其他

| 功能 | 说明 |
|---|---|
| 详情弹窗 | 按「类别 + 分类表行 ID」取**完整字段**（不依赖列表里被截断的内容），技术字段（行 ID、客户端 ID、来源 IP、入库时间）一并展示；`tips` 等长文本占整行 |
| 深链 | `/logs?category=network_ipc_communication` 可直接定位到某个类别，切换类别会同步到地址栏 |
| 导出（小结果集） | ≤5000 条：前端逐页拉齐后生成 CSV（带 BOM + **公式注入防护**） |
| 导出（大结果集） | >5000 条：创建后端异步导出任务 → 每 1.5 秒轮询 → 完成后下载，浏览器不加载全部数据 |
| 错误降级 | 查询失败保留上一次成功数据，显示错误条与"数据更新时间" |

## 4. 原始日志存证与完整性校验 `/integrity`

### 概览

- **存证策略说明条**：明确"原始字节先保存、后解析；每条日志独立计算 SHA-256"，展示算法版本 `EVIDENCE-V1`
- **4 张统计卡**：今日原始日志（已计算哈希比例）、已完成哈希（算法 + 待校验条数）、
  校验正常（最近校验通过率）、校验异常（需要复核，含哈希不一致与原始日志缺失）

### 筛选

主机名称 / 来源 IP、日志类别、校验状态、开始时间、**SHA-256 精确检索**
（前端先校验必须是 64 位十六进制，不合规直接提示、不发请求；后端仍会再校验一次）。

### 列表（11 列）

序号、接收时间、存证 ID、主机、来源 IP、融合类别、日志类型、
**SHA-256**（中间省略显示，悬停看完整值，点复制按钮复制完整 64 位）、
校验状态、最近校验时间、操作（详情 / 校验）。

校验状态四种配色：校验正常（绿）、哈希不一致（红）、原始日志缺失（红）、待校验（橙）。

### 校验功能

| 功能 | 说明 |
|---|---|
| 单条校验 | 行内"校验"按钮，按钮带加载态，**只更新该行**，不清空列表 |
| 重新校验当前页 | 只发**当前页实际显示的 ID**（最多 100 条），后端同步执行；完成后刷新列表与统计，并提示"已校验 N 条，发现 M 条异常" |
| 防重复 | 同一条在途时忽略重复点击 |

### 详情弹窗（五个部分）

1. **存证信息**：存证 ID、校验状态、接收时间、客户端 ID、主机/来源 IP、最近校验时间、存储路径、offset/length、哈希算法
2. **哈希证明**：算法版本、摘要长度、完整 `raw_hash`（可一键复制）
3. **原始日志正文**：后端按 路径 + offset + length 现读的原文；读不到时显示"文件不存在或无法读取"
4. **融合日志关联**：类别、类型、`normalized_table`、`normalized_row_id`
5. **单条完整性校验**：三步结果（原始文件是否存在 → 原始字节是否读取成功 → SHA-256 是否一致），异常步骤标红

弹窗内可直接"重新校验这一条"。

### 其他

| 功能 | 说明 |
|---|---|
| 导出存证记录 | 按当前筛选条件，由**后端流式写出 CSV**（浏览器直接下载，不把数据加载进内存） |
| 刷新策略 | 顶部统计每 5 秒刷新；**列表不自动刷新**，避免看详情或翻页时内容跳动 |
| 明确不做 | 批次存证、Merkle 根、数字签名、链式哈希、异步校验任务（页面与接口都没有） |

## 5. 三个页面共有的行为

| 行为 | 说明 |
|---|---|
| 统一响应 | 只取 `{code,message,data}` 里的 `data`；`code != 0` 时直接展示后端返回的 `message` |
| 错误分级 | 首次失败：错误条 + 重试按钮；**连续失败 ≥2 次**：提示升级为"已连续 N 次失败"，恢复后自动消失 |
| 数据保留 | 任何一次失败都**不清空页面**，保留上一次成功数据并显示"数据更新时间" |
| 请求取消 | 切换类别 / 重新查询时，自动取消上一个未完成的请求，避免旧响应覆盖新结果 |
| 时间显示 | 接口统一 UTC ISO 8601，页面转浏览器本地时区；列表优先用后端算好的延迟秒数，不用本机时间重算 |
| 状态映射 | 接口只返回英文枚举，中文文案与颜色在前端集中映射 |
| CSV | 一律带 UTF-8 BOM，且对 `= + - @` 开头的单元格做公式注入防护 |
| 响应式 | 断点 1400 / 1250 / 1180 / 1000 / 760px；1680px 下表格无需横向滚动，窄屏卡片与筛选自动折行 |
| 骨架屏 | 心跳页概览卡在首屏加载时显示骨架，避免数字闪动 |

## 7. 技术栈与运行

| 项 | 版本 / 命令 |
|---|---|
| 框架 | Vue 3.5、TypeScript、Vite 6、Vue Router 4、Pinia |
| 界面 | Element Plus（主题已对齐原型的蓝色与 3px 圆角）、lucide-vue-next 图标 |
| 图表 | ECharts（只初始化一次，用 `setOption` 更新） |
| 时间 | dayjs + `Intl` 本地化 |

```bash
cd D:\log-Frontend
npm install
npm run dev:all     # mock 假后端(8080) + 前端(5173)，8080 已有服务则自动跳过 mock
```

其它：`npm run dev`（只起前端）、`npm run mock`（只起假后端）、
`npm run build`（类型检查 + 生产构建，产物 `dist/`）、`npm run typecheck`。

后端就绪后把 `dist/` 交给 Nginx，`/api` 反代到 8080；Vue 是 history 路由，
Nginx 需要 `try_files $uri $uri/ /index.html`，SSE 需要关闭代理缓冲。
